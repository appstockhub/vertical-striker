### 発見と修正: テンポ変更でカーブが死んでいた

- 換算後の側方加速度 0.0036px/tick² が固定小数点の量子化下限 (1/256=0.0039) を割り、
  さらに斜め方向は fixedMul の切り捨てで完全にゼロ。実測の横ずれは全飛程で **0.31px**
- **修正: 「毎tick加速度を加算」→「4tickごとに速度ベクトルを4/256rad回転」方式へ再設計**
  (`ballPhysics.ts`)。乗算相手が速度そのもの (数百raw) なので量子化に強く、合計曲げ角17.9°は
  旧設計と同水準。摩擦は回転後のベクトル全体に掛かるため側方成分だけが減衰することもない
- K7ゲートの再導出: 旧8px(絶対量)は飛程591px時代の校正値。摩擦を原作値へ直した今は
  飛程82pxなので、**曲がりの不変量は「飛程に対する比」**: 旧1.9% → ゲート2%、実測4.0%で合格

## 24周目-2: サイクル② ドリブルの離散タッチ化 (2026-08-17)

**実装** (`src/sim/dribble.ts` 全面書き換え + `ballPhysics.ts` + `update.ts` + AI 2件):

1. **離散タッチモデル**: 追従サーボを廃止。接触半径 (12→7px、原作D1に合わせた) に入った
   tickだけ入力方向へ押し出す (タッチ1.2px/tick)。触れていない間はボールに一切干渉しない
2. **タッチクールダウン (9tick)**: 「蹴る→追う→蹴る」のリズムの実体。無いと接触半径内で
   数tickごとに再タッチされ実質サーボに戻る (実測で確認)
3. **低速転がり減衰帯** (<1.25px/tick で 0.85/tick): タッチしたボールが数tickで沈む。
   キック(1.86〜2.7)は速度が出ている区間の挙動不変、終端の惰性30px程度だけが消える
4. **トラップ**: ニュートラル入力で足元の遅いボールを減衰 (不具合#7の恒久対策)
5. **蹴り出しドリブル**: インパルス2.0px/tick (不具合#6の修正、デッドコード解消)

**設計スイープの記録**: タッチ速度は 1.0(置き去り発生) / 1.2(採用: gap 0.42身長・周期10tick)
/ 1.4(周期22tickで超過) を実測して決定。成立条件は「クールダウン中のボール移動距離 ≥
選手移動量」(これを割ると選手がボールを追い越して置き去りにする)。

**サーボ廃止で露呈した構造的依存 3件 (すべて根治)**:

1. **CPUのセットプレー再開はサーボの副作用で偶然成立していた**: キッカーが歩き出した瞬間に
   サーボがボールを吸着して「ボールが動いた=ロック解除」。→ `SetPieceLock.kickerIndex` を
   新設してキッカーをロック中ボール脇に待機させ、**CPUは90tick (原作実測S1=GK配球1.5秒)
   後に明示的に蹴る** (`CPU_RESTART_DELAY_TICKS`)。ロック中の非操作選手のタッチも禁止
   (GK確保が1タッチで無防備になるのを防ぐ)
2. **CPU攻撃AIは「holder=足元にボールがある」を仮定していた**: サーボ廃止でボールが20px先を
   転がるようになると、「ゴールへ歩く」と追跡権の「ボールへ向かう」が2tick周期で衝突し、
   フリーボールの20px手前で3600tick静止するデッドロックを実測。→ 接触半径の外では
   まず回収に向かう (回収境界は接触半径と厳密一致させる。7〜9pxの隙間を残した初版は
   全セル系統の新振動を生んだ)
3. **primary追跡者の合成ステアリング均衡**: 至近(48px)のボールへは重み合成を捨てて純追跡
   (`PRIMARY_PURE_CHASE_RADIUS`、17周目のdeadzone内停止修正と同じ考え方の拡張)
