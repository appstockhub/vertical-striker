## なぜ確認が必要か（2026-08-17 に原文を再取得して裏付け済み）

**このアセットページには License 欄が存在しない。** itch.io の "More information" 表に
あるのは Status / Category / Rating / Author / Genre / Tags / Content だけで、
ライセンスを示すメタデータが1つも無い（HTMLを直接確認）。本文の説明も内容物の列挙のみ。

つまり CC0 の根拠は**作者コメント1件だけ**であり、しかもそのコメントの中で本人が
「自分の素材は一般に継承付き」とも書いている。以下は同一投稿の原文（誤字も原文ママ）:

> "Hi, you can use the assets in commercial and non commercial projects. **If you make
> modifications and you share them you must use the same license, CC-BY-SA or CC-BY-.4.0,
> and credit me 'Chasersgaming'.**
>
> There is some confusion over my licensing, for which I am trying sort, and will hopefully
> have that sorted with the newer works. I originally set my license for CC-BY-SA, but itch
> does not include it as an option, so I had to select CC-BY-4.0 in the metadata as this was
> the closest.
>
> **That said this particular asset(footaball) is CC0, public domain** so you are free to use
> how you want for what you want, commercial, non commercial, make modifications,edit etc
> with no credit necessary, although always appreciated.:)"

CC0 なら制約なし、CC-BY-SA なら**改変したアート資産を同ライセンスで公開する義務**が発生し、
将来の Steam 販売の判断に影響する（V-3 のユーザー判断: 継承義務のある素材は採用しない）。

さらに確認すべき点が2つある:
1. **このコメントは約2年前のもので、パックのファイル更新（2024-06-26）より前**。
   現行版（`U2024`）にも同じ CC0 が及ぶのか明示されていない。
2. 傍証として OpenGameArt に同作者の [Football/Soccer Assets](https://opengameart.org/content/footballsoccer-assets)
   があり、そちらは正式に **CC0** タグ付き。ただし**中身はピッチ画像1点のみ**で、
   itch.io の £2 パックに入っている選手スプライトは含まれていない。
   → OGA の CC0 表示は選手スプライトの根拠にはならない。

**購入前に書面で確定させ、回答のスクリーンショットを保全すること。**
