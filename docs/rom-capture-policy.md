# rom-capture-policy.md — 原作カセット吸い出しと参照利用の規約

作成: 2026-08-18（24周目-7、エミュレータ・イン・ザ・ループ・パリティハーネスの実現可能性調査）。
本書は当プロジェクトにおける原作ROMの取り扱い規約を定める。**法的助言ではない**。
判断に迷う事項が生じた場合は作業を止めてユーザーの判断を仰ぐこと。

---

## 1. 前提と目的

- 目的は**挙動の観察**である: フレーム単位の入力に対する原作の応答（ボール物理・選手挙動・
  カメラ・アニメーションのタイミング）を計測し、自作simのパリティ検証の正解データにする
- 現行手法（YouTube 30fps動画の外部観察）は、圧縮・VFR・遠近の系統誤差±40%・
  入力が観察できない、という限界により完全トレースに到達できないと判断された（24周目-7）

## 2. 私的複製の範囲（運用ルール）

1. **吸い出し元はユーザー自身が所有するカセットのみ**。借用品・レンタル品からの
   吸い出しは行わない
2. **吸い出し作業はユーザー自身が行う**（吸い出し代行サービスは利用しない）
3. 吸い出したROMイメージは**ユーザーの私的使用の範囲でのみ**利用する:
   - 用途はローカルPC上のエミュレータでの再生・計測に限定する
   - **配布・共有・アップロードは一切行わない**（クラウドストレージ含む）
   - カセットを手放す場合はROMイメージも破棄する
4. SFCカセットのROM読み出しに技術的保護手段の回避は伴わない（SFCカートリッジの
   ROMは暗号化されていない）。**保護手段の回避を要する手段は使用しない**

## 3. クリーンルーム方式の原則（CLAUDE.md 素材ポリシーの具体化）

当プロジェクトの成果物（コード・アセット・ドキュメント）に持ち込んでよいのは
**観察した挙動・数値のみ**である。

| 持ち込んでよい | 持ち込んではならない |
|---|---|
| 実測した数値（速度・周期・フレーム数・距離・色の測定値） | ROMイメージ・その断片 |
| 挙動の記述（「Bを30F押すと弾道が高くなる」等） | 逆アセンブル・逆コンパイルの結果、コード片 |
| 画面構図の測定値（俯角・可視範囲・スケール比） | スプライト・グラフィック・音声データの抽出物 |
| 入力→応答の対応表 | メモリマップ・内部変数の解析結果 |

- **逆アセンブル・逆コンパイル・メモリ解析は行わない**。エミュレータのデバッガ機能・
  メモリビューアも使用しない。観察は「画面に映るもの」と「入力」の対応のみ
  （エミュレータのLua APIも、入力注入・フレーム制御・画面キャプチャに限って使う）
- 抽出したフレーム画像・動画は分析専用の中間物であり、成果物・リポジトリに含めない
  （既存の参照動画と同じ扱い。docs/visual-behavior-audit.md の運用を踏襲）

## 4. リポジトリ衛生（機械的強制）

- ROM・吸い出しデータ・エミュレータのキャプチャは**絶対にコミットしない**。
  `.gitignore` に以下を追加済み:
  - `*.sfc` / `*.smc` / `*.srm` / `*.bk2` / `*.bs`（ROM・セーブ・ムービー）
  - `roms/`（置き場を一箇所に限定する）
  - `scratchpad/emu/`（エミュレータのキャプチャ・作業領域）
- ROMの置き場は**リポジトリ外**（例: `C:\Users\tennp\roms\`）を第一候補とし、
  リポジトリ内に置く場合は `roms/` ディレクトリのみを使う（gitignore対象）
- コミット前に `git status` でROM系ファイルが staged されていないことを確認する
  （批評役の検分項目にも含める）

## 5. 既存ポリシーとの関係

- CLAUDE.md「原作および他の商用ゲームの素材は一切使用しない」は**変更しない**。
  本規約はその枠内で「挙動の数値の取得手段」を外部動画からエミュレータ実測へ
  格上げするものである
- `docs/asset-credits.md` の記録義務は従来どおり（本ハーネスは素材を生まないため
  記録対象は増えない）
