調査方法:
1. **Web調査** (テキスト情報のみ。ROM解析・逆アセンブルは一切参照していない)

## E. 検証したが**採用しなかった**こと

- **無入力時のオートパイロット** (操作選手を無入力の間はAIで動かす)
  → 無操作試合のスコアは 0-44 → 0-39 とほぼ改善せず (=守備崩壊の主因ではない)、
     逆に「スティックを離すと自分の選手が勝手に走り出す」操作感の劣化を招くため撤回。

## F. 保留 (ユーザー判断が必要 / 次にやるべき)

| # | 内容 | 補足 |
|---|---|---|
| **P1** | **人間が下手だと大量失点する** | 実測: まともに操作する試合は **0-1 / 0-2** と正常。無操作だと **0-39〜44**。キーパー単体の阻止率は86〜97%と正常なので、原因は「守備側フィールドプレイヤーがCPUの持ち上がりを止められない」こと。守備AIの強化はゲームバランス(難易度設計)そのものなので、**どのくらい歯ごたえが欲しいか**の方針を先に決めたい |
| **P2** | **人間側のシュートが極端に少ない** (0〜11本 vs CPU 43〜59本) | サポートランがボール保持前提のため、前線に人が出て行かない。攻撃AIの作り直しが必要 |
| P3 | 選手個性パラメータ (走力/キック力/テクニック) | 原作の評価「どの選手も生きている感」の核。Phase 4後半の大物 |
| P4 | 試合前設定の拡張 (フォーメーション選択の露出) | 現状は難易度とオフサイドのみ |
| P5 | カード/退場 | 17周目にファウルは実装済み。カードは人数前提が変わるため保留のまま |
| P6 | 観客の歓声・ゴール時の盛り上がり | BGMは入ったので次はSE側 |
