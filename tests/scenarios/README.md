# tests/scenarios/ — 操作シナリオ検証（機械判定）

人間入力を模したスクリプトで「操作ごとの成立」を機械判定するシナリオ群（24周目新設）。
`harness.ts` の `runScript` が入力列を流し、tickごとのトレースに対して成立条件を assert する。

## ラチェット規約（重要）

- **成立しているシナリオは `it(...)`** — 回帰ゲート。壊れたら即検知
- **既知の不具合で不成立のシナリオは `it.fails(...)`** — 「今は失敗する」宣言。
  修正が入って成立すると vitest が「fails指定なのに通った」とエラーを出すため、
  **`it` への昇格（=ラチェット化）が強制される**。昇格漏れが構造的に起きない
- 昇格するときは `it.fails` → `it` に変えるだけ。コメントの「不具合#n」参照は残すこと
